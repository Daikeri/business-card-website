# Мир камня

Тестовый сайт-визитка для просмотра заказчиком. HTML, CSS и JavaScript без сборки и серверной части.

## Публикация на GitHub Pages

Сайт работает как набор статических файлов. Установка зависимостей, сборка и локальный сервер не нужны.

1. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
2. Отправьте изменения в ветку `feature/business-card-site` (текущий прототип) или `main`. Workflow `.github/workflows/pages.yml` автоматически опубликует сайт.
3. Дождитесь успешного завершения **Actions → Deploy GitHub Pages**. Ссылка на опубликованный сайт появится в результате deployment и в **Settings → Pages**.

Ожидаемый адрес: https://daikeri.github.io/business-card-website/ (после первой успешной публикации).

Обе ветки публикуют один и тот же сайт: последняя публикация заменяет предыдущую. После согласования прототипа удалите `feature/business-card-site` из списка `on.push.branches` в workflow, оставив `main`. Если окружение `github-pages` ограничивает ветки, разрешите публикацию из этих веток в **Settings → Environments → github-pages**.

Настройка workflow соответствует [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Оформление и фотографии

Вверху страницы закреплён общий переключатель четырёх оформлений. Выбор применяется ко всей странице без перезагрузки и сохраняется в `localStorage`. Если хранилище недоступно, переключение продолжает работать; по умолчанию включена «Классика».

- **Классика** — светлый фон, глубокий зелёный, шрифт с засечками, симметричная композиция и галерея в три колонки.
- **Графит** — тёмный фон, песочные акценты, геометрический шрифт, фотография рядом с описанием и галерея в четыре колонки.
- **Воздух** — оформление и шрифты «Классики» в холодной светло-голубой гамме.
- **Океан** — оформление и шрифты «Графита» в тёмной сине-зелёной гамме с мятными акцентами.

Во всех вариантах сохранён дословный текст заказчика: название, низкие цены, телефон и описание услуг. Ниже — единая галерея всех 29 фотографий в исходном порядке, без категорий и придуманных подписей. Фотографии показаны без подложек, рамок и значков «+»: скруглено само изображение, его исходные пропорции в галерее сохранены. Первый экран занимает как минимум высоту окна за вычетом верхней панели: галерея начинается отдельным блоком после прокрутки или нажатия «Смотреть фотографии». При небольшой высоте окна или увеличении текста вводный блок свободно растёт без обрезания. В «Графите» и «Океане» на широких экранах рядом с описанием показана первая фотография; нажатие открывает её оригинал. На мобильных экранах этот дополнительный снимок скрыт, галерея показывает две колонки. Варианты 1/3 и 2/4 используют общие правила компоновки и отличаются только палитрой.

В `assets/` находятся WebP-превью, в `raw/` — оригиналы. `photos.js` содержит только пути к фотографиям. Нажатие на карточку открывает оригинал целиком на тёмном фоне. В просмотрщике остаются только стрелки, закрытие и один счётчик фотографий; зум, повторная подпись, ссылка на оригинал и подсказки убраны. Работают клавиши ←/→, Escape и свайпы. После закрытия фокус возвращается на выбранную карточку.

Шрифты Cormorant Garamond, Manrope и Golos Text с кириллицей хранятся локально в `assets/fonts/`, вместе с лицензиями OFL. Внешние запросы к сервисам шрифтов не нужны. `styles.css` содержит базовые стили и просмотрщик, `design.css` — четыре оформления и адаптивные правила, `theme.js` — переключение и восстановление выбора до загрузки стилей.

Для статического хостинга нужны `index.html`, `styles.css`, `design.css`, `theme.js`, `app.js`, `photos.js`, `assets/` и `raw/`. Workflow GitHub Pages копирует все эти файлы. Локально можно открыть `index.html` в браузере.
