# Мир камня

Тестовый сайт-визитка для просмотра заказчиком. HTML, CSS и JavaScript без сборки и серверной части.

## Публикация на GitHub Pages

Сайт работает как набор статических файлов. Установка зависимостей, сборка и локальный сервер не нужны.

1. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
2. Отправьте изменения в ветку `feature/business-card-site` (текущий прототип) или `main`. Workflow `.github/workflows/pages.yml` автоматически опубликует сайт.
3. Дождитесь успешного завершения **Actions → Deploy GitHub Pages**. Ссылка на опубликованный сайт появится в результате deployment и в **Settings → Pages**.

Ожидаемый адрес: https://daikeri.github.io/business-card-website/ (после первой успешной публикации).

Обе ветки публикуют один и тот же сайт: последняя публикация заменяет предыдущую. После согласования прототипа удалите `feature/business-card-site` из списка `on.push.branches` в workflow, оставив `main`. Если окружение `github-pages` ограничивает ветки, разрешите публикацию из этих веток в **Settings → Environments → github-pages**.

Настройка workflow соответствует [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Варианты оформления

- [Светлая композиция](https://daikeri.github.io/business-card-website/?layout=light) — фотография справа.
- [Тёмное оформление](https://daikeri.github.io/business-card-website/?layout=dark) — фотография на весь первый экран.
- [Каталог](https://daikeri.github.io/business-card-website/?layout=catalog) — компактный первый экран и плотная галерея.

Переключатель закреплён сверху. Выбор сохраняется в браузере; параметр ссылки имеет приоритет. После публикации ссылки можно отправлять заказчику. Все пути к ресурсам относительные и поддерживают размещение в подпапке `/business-card-website/`.

## Фотографии и содержание

Все 29 исходных фотографий из `raw/` включены в галерею. В `assets/` находятся облегчённые WebP-превью; `photos.js` содержит список фотографий, подписи и категории. В просмотрщике доступны оригинал, увеличение, прокрутка увеличенного снимка, стрелки, клавиши ←/→, Escape и свайпы. Фильтр галереи определяет набор снимков при перелистывании.

Название, телефон и описание взяты из пожеланий заказчика. Адрес, цены в рублях, часы работы и другие неподтверждённые сведения не добавлены. Шрифты загружаются из Google Fonts; без сети используются системные шрифты.

Для статического хостинга нужны `index.html`, `styles.css`, `app.js`, `photos.js`, `assets/` и `raw/`. Панель вариантов предназначена для согласования дизайна.
